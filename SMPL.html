Model and related tools

For questions about the code, please make sure to check the FAQs before contacting us. The SMPL model is available for non-commercial research, education, and artistic purposes only. By downloading the model you agree to the license terms.
The model is also available for commercial purposes by contacting sales@meshcapade.com.
If you are unsure whether your use counts as non-commercial please contact smpl@tuebingen.mpg.de before downloading the model.

Overview:

SMPL is an easy-to-use, realistic, model of the of the human body that is useful for animation and computer vision.
SMPL lets you create realistic human body shapes with realistic deformations.
Available here is a version of SMPL that is similar to that described in this paper.

SMPL for Maya

Included in this download:

  • Male and female models (FBX format)
    • Female model: basicModel_f_lbs_10_207_0_v1.0.2.fbx
      • MD5: 81a57177f8cbf584f8d6379742c99e2e
      • Also referred to as: SMPL_female_010_207.fbx
    • Male model: basicModel_m_lbs_10_207_0_v1.0.2.fbx
      • MD5: 67542f27aa4bc6b8d12da28fdce51539
      • Also referred to as: SMPL_male_010_207.fbx
    • Default mesh. The average SMPL body.
    • Rigged skeleton, using LBS
    • 10 shape blendshapes
    • 207 corrective pose blendshapes
    • UV map
  • Script and data to use SMPL in Maya
    • If you want to edit body shape or repose the mesh, you need to run the script.
  • README.txt for installation and license instructions

Dependencies

Numpy is required for running this script. Numpy is a Python module that can be installed following the instructions given here or here

Please make sure you have numpy installed on your computer and accessible through Maya's Python. We are working towards removing this dependency.

SMPL for Blender

This Blender add-on allows you to add SMPL skinned meshes to your current Blender scene. Each imported SMPL mesh consists of a shape specific rig, as well as shape keys (blend shapes) for shape and pose correctives.

  • Requirements: Blender 2.80+
  • Additional dependencies: None
  • Used SMPL model: SMPL v1.0 with 10 shape components

Installation instructions    Download SMPL Blender Add-on (20210611, 34MB)
