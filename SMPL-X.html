SMPL-X Blender Extension Add-on

This Blender extension add-on allows you to add SMPL-X/SMPL+H skinned meshes to your current Blender scene. Each imported SMPL-X/SMPL+H mesh consists of a shape specific rig, as well as shape keys (blend shapes) for shape, expression (SMPL-X only) and pose correctives.

  • Requirements: Blender 4.5+
  • Additional dependencies: None
  • Supported body models:
    • SMPL-X
      • 300 shape components, 100 expression components, flat hand 
      • locked head (no head bun) and v1.1 (optional DLC)
      • female/male/neutral
    • SMPL+H (optional DLC)
      • 300 shape components, female/male/neutral
  • Videos
    • Short overview
    • CVPR 2021 Tutorial
  • Code repository: https://gitlab.tuebingen.mpg.de/jtesch/smplx_blender_addon
  • See README in code repository for further details including installation instructions

Blender add-on feedback and questions: smplx-blender@tuebingen.mpg.de

SMPL-X Unity Package

This Unity project contains the SMPL-X Unity package which allows you to add SMPL-X skinned meshes to your current Unity scene. Each imported SMPL-X mesh consists of a shape specific rig, as well as shape keys (blend shapes) for shape, expression and pose correctives.

  • Requirements: Unity 2020.3.8 (LTS) or later
  • Additional dependencies: None
  • Used SMPL-X model: SMPL-X v1.1 with 10 shape components, 10 expression components, flat hand
  • Code repository: https://gitlab.tuebingen.mpg.de/jtesch/smplx-unity
  • Video: CVPR 2021 Tutorial
